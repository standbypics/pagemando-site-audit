# Code of Conduct

We want this to be a welcoming project. Be respectful, assume good faith, give constructive feedback, and do not harass, threaten, discriminate against or publish private information about other contributors.

To report a conduct concern privately, contact info@standbypics.com. Maintainers will review reports confidentially where feasible and may remove abusive content or limit participation. This code applies to project discussions, issues, pull requests and other project spaces.
