# Contributing to PageMando Site Audit

Thank you for helping make website auditing more accessible to small teams.

1. Open an issue to discuss major feature changes before coding.
2. Fork the repository and create a descriptive feature branch.
3. Run `npm test` and `npm run check` (Node.js 20+).
4. Include tests for bug fixes and behavioral changes.
5. Submit a pull request describing the problem, solution, and how you tested it.

Be respectful and follow the [Code of Conduct](CODE_OF_CONDUCT.md). Do not include private client websites, API tokens, or personal data in issues or fixtures. Contributions are accepted under the repository's MIT license. Maintainers review incoming PRs; opening a PR does not guarantee acceptance.

**Good first issues:** fixture coverage for malformed titles, handling redirect link reporting, or documentation improvements that correct real errors. Please verify an issue exists before starting duplicate work.
